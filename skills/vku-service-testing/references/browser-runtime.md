# Браузерный процесс и адаптеры

Для Playwright использовать установленный Chrome или доступный совместимый браузер по выбору пользователя. Safari/safaridriver — иной движок, его не выдавать за Playwright. При проблемах Safari предложить конкретный переход, не менять выбор молча.

Установить зависимости в каталоге проекта, дать команды с `cd "<абсолютный путь>"`. npm из домашнего каталога не найдёт package.json. Вход — `npm run login` в пользовательском терминале либо в интерактивном exec с tty=true: readline без открытого stdin закроется и закроет окно браузера. Не автоматизировать пароль/капчу. Отдельный persistent-профиль, один процесс на профиль. Отчёт о другом обычном окне Chrome не является наблюдением тестового окна.

Ожидания — по состоянию, не фиксированные sleep. Сначала именованные поля и доступные роли, затем проверенные DOM-привязки. Не выбирать первый попавшийся элемент при неоднозначности. Проверять реальную персонализацию и одну основную кнопку для текущего действия; вопросы могут иметь несколько кнопок-ответов.

Наблюдения на одной из реализаций ВКУ (переиспользовать после проверки DOM текущей версии):

- GAR отображался как textarea внутри адресного виджета. Выбор улицы вызывает normalize; дождаться завершения и актуального значения прежде, чем выбрать дом. Закрыть подсказки перед «Нет квартиры». Нормализация может добавлять индекс, менять точки/регистр — сравнивать адрес осмысленно, сохраняя дом/корпус/квартиру.
- Скрытый native checkbox/radio переключать видимым label[for], затем проверять checked. Не применять force для маскировки ошибки взаимодействия.
- Заполненный Lookup может показывать карточку и скрывать combobox. Для повторного поиска пользоваться штатной «Очистить поле», а не ждать несуществующий видимый input.
- FileUploadComponent задаёт типы как fileType и/или maxCountByTypes[].type. SIG не путать с PDF. Имя принятого файла может отображаться без расширения. Наличие имени без проверки ошибок загрузчика не доказывает приём файла.
- Для SIG использовать предоставленный/существующий разрешённый тестовый файл. Не выдумывать криптографически действительную подпись. Проверка загрузки SIG не равна проверке подписи нотариуса.
- Rich text может быть contenteditable с name=ID компонента. Не считать его обычным textarea.
- MapService может менять заголовок на «Выберите подразделение». Выбор карточки через «Выбрать» способен сразу перейти в УКП: дополнительное «Продолжить» тогда неверно. Сверять выбранное подразделение с XML/PDF. Не подменять отсутствующий ожидаемый МФЦ случайным первым.
- «Ничего не найдено» при карте может предшествовать загрузке SDK. Проверить запросы внешней карты и справочника, вычисленный адрес и время готовности; таймаут библиотеки отделять от пустого справочника и ошибки конфигурации. Разумно увеличить ожидание готовности, если установлена эта причина, сохранив сбой в истории.

Пассивно наблюдать getService/getNextStep, display.id и finishedAndCurrentScreens для скрытых расчётов. Текст кнопки и последовательность запросов проверять вместе с UI. При таймауте сохранить текущий URL, ошибки запросов, скриншот, DOM/HTML и trace; проверить, не произошёл ли выход в ЕСИА. При недоступности входа продолжить статические проверки, запросить восстановление сессии, затем повторить заблокированный кейс.

Смена файла настроек требует нового сопоставления со стендом. Старый опубликованный маршрут может не содержать новых экранов даже при верном локальном экспорте; проверить публикацию до исправления формул.
