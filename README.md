# Скиллы и навыки для ВКУ Госуслуг

Набор практических навыков для разработки и проверки форм в визуальном конструкторе: от модели экранов и вычислений до браузерных автотестов и проверки документов.

| Навык | Что делает |
|---|---|
| [vku-vm-templates](skills/vku-vm-templates/SKILL.md) | Проектирует и проверяет экраны, переходы, JSON Logic и linkedValues; сопоставляет поля с XSD; помогает создавать и проверять XML/PDF-шаблоны Velocity |
| [vku-service-testing](skills/vku-service-testing/SKILL.md) | По URL формы и пути к настройкам составляет кейсы, пишет и запускает Playwright-скрипты, ведёт журнал попыток и покрытия, сохраняет и проверяет сформированные документы |

## Использование

Скопируйте каталоги навыков в каталог skills вашей среды. Для актуальной установки Codex используются `.agents/skills/` в проекте или `~/.agents/skills/` для пользователя; у отдельных установок может использоваться собственный каталог. См. [официальную документацию установки навыков](https://developers.openai.com/api/reference/cli#use-the-cli-from-a-coding-agent).

Начните новую сессию и вызовите нужный навык:

```text
Используй $vku-service-testing.
URL: https://example.test/form
Настройки: /path/to/service-settings.json
Составь кейсы, реализуй автотесты и зафиксируй результаты.
```

Для формы:

```text
Используй $vku-vm-templates.
Проверь настройки, переходы и ограничения полей по приложенной XSD.
Дай точные действия для переноса в конструктор.
```

## Что входит в тестовый навык

- Скрипт bootstrap.py для инвентаря настроек и создания проекта Playwright.
- Каркас с отдельным профилем браузера, контролем версии JSON, журналом результатов и блокировкой неразрешённых эффектов.
- Методика сокращения кейсов с сохранением покрытия и проверки логических концов.
- Наблюдение скрытых расчётов, работа со сложными компонентами и сохранение пакетов документов.
- Проверка выбранных XML/PDF из ZIP; XSD, бизнес-сверка и визуальный просмотр отмечаются раздельно.

Каркас не угадывает требования услуги. Агент заполняет cases.mjs и адаптеры по конкретной форме; пустой набор кейсов не запускается как успешная проверка. Для запуска нужны Node.js, Playwright и доступный браузер. Для проверки документов — Python с lxml/pypdf; для рендера PDF — pdftoppm.

## Принципы

Настройки формы используются только для чтения. Ожидаемый маршрут выводится из требований независимо от правил, которые проверяются. План, автоматический успех, ручное подтверждение и блокировка различаются. Достижение подписания не равно отправке заявления. Полнота проверяется по наблюдениям и артефактам; попарное покрытие не называется полным перебором.

Разрешение на подписание или отправку относится к текущей задаче и области действия. Профиль, учётные данные, реальные формы, исходные заявления и результаты пользовательских прогонов в комплект не входят.

## Проверка комплекта

Python-помощники проверяются командой:

```bash
python3 skills/vku-service-testing/scripts/test_helpers.py
```

Тесты с XSD требуют lxml. Инструкции и технический каркас опубликованы без привязки к конкретным услугам и территориям.
